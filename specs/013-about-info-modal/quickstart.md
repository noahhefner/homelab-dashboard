# Quickstart: About Info Modal

**Feature**: 013-about-info-modal
**Date**: 2026-09-06

## Scope

Replace the homepage navbar GitHub link with an "About" button that opens a Bootstrap modal containing: the dashboard title, the author's name, a project blurb, config-file guidance, and a GitHub link. The About modal lives only on the homepage.

## What Changes

| Artifact | Change |
|----------|--------|
| `app/templates/index.html` | Replace the GitHub `<a class="...github-link">` in the navbar with an About `<button data-bs-toggle="modal" data-bs-target="#about-modal">`; add the about modal markup |
| `assets/app.css` | Repoint the `.github-link` selector group to `.about-toggle` (base, `:hover`, dark-mode hover, `:focus-visible`) |
| `tests/integration/test_about_modal.py` | NEW — first (Test-First, Principle IV). Asserts button semantics, modal presence/content, no leftover GitHub navbar link, config page unchanged |
| `assets/` JS bundle | No change — Bootstrap's Modal JS is already bundled (`assets/app.js` imports `bootstrap.bundle.min.js`) |

## Implementation Order (Phase 2/3)

1. **Write the tests first** (`tests/integration/test_about_modal.py`) — they fail against the current template (a `github-link` anchor still exists, no modal).
2. Edit `app/templates/index.html` — swap the anchor for the About button; add the modal markup (per `contracts/html-contract.md`).
3. Edit `assets/app.css` — rename `.github-link` → `.about-toggle` in the four selector groups.
4. Rebuild the static bundle with `pnpm build` (regenerates `app/static/`) and add the new `app-*.js` asset to `app/static/manifest.json`… *note: rebuild and manifest regeneration are handled by the normal build* — if the manifest is generated by Vite's `generate-asset-manifest` plugin, the rebuild updates `app/static/manifest.json` automatically; the Flask `js_assets` list is loaded from that manifest.
5. Run `make check` (ruff, format, djlint, prettier — CSS is covered by prettier; the HTML/CSS edits must stay formatted) and the full pytest suite.

## Definition of Done

- [ ] Homepage navbar shows an About icon button (no GitHub icon) that opens the modal
- [ ] Modal shows: heading, author name, project blurb, config-file guidance, GitHub link (new tab + `noopener noreferrer`)
- [ ] Modal closes via close button, backdrop click, and Esc; no page navigation on open
- [ ] Dark mode legible (Bootstrap `data-bs-theme`)
- [ ] Config editor page unchanged
- [ ] `tests/integration/test_about_modal.py` passes; full suite passes; `make check` clean

## Validation / Known Constraints

- Bootstrap JS must remain present in the page bundle for `data-bs-toggle="modal"` to work — do not remove the `bootstrap.bundle.min.js` import from `assets/app.js`.
- The GitHub href is unchanged from the removed navbar link (`https://github.com/noahhefner/homelab-dashboard`).
- djlint (or its configured Jinja rules) runs over `index.html` — keep the modal markup lint-clean (self-closing/normal void elements, quoting).
